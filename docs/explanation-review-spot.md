# 为什么对照卡贴在框旁边

审稿员要同时看见稿上的字和确认单上对应的字。右栏清单还要留着，用来看整单还剩几条，以及签字和退回。打开「对照」后，当前这一条的详情从右栏移到稿件上，贴在当前框旁边。右栏清单不变。

数字、键名和函数见 [审稿合同](contracts/review.md#就地对照)。操作步骤见 [怎么使用对照](howto-review-spot.md)。

## 问题

0.31.1.16 之后，点一条问题不会自动放大。只有画面已经大于 1 倍，才会平移让框居中。详情在右侧 320px 的清单里。稿件很宽时，审稿员要在稿上的字和右栏之间来回看。

如果把这一条的全部分框都画出来，一条长句会分成很多小框，看不出这一条从哪里开始、到哪里结束。如果拿掉右栏、改成满屏浮窗，整单进度和签字按钮就没有固定位置。

## 做法

```
清单（右栏 320px，一直在）
稿件
  只画当前这一条：透明的段落框，加错点下方的细下划线
  编号钉在错点框外角
  对照卡不随稿件缩放。没拖动过时，贴在左右空档较大的一侧，不压住段落框；拖动过后，留在放下的位置
        下面这张图是右侧空档较大的情况
        ┌──────── 当前段落 ────────┐  ┌─ 对照卡 440px ─┐
        │  稿上的这一段              │  │ 读到 / 标准或片段 │
        └──────────────────────────┘  └─────────────────┘
```

段落框的宽和高都超过页面的 90% 时，不画段落框，改画错点框。放大稿件时，框跟着稿件放大，对照卡的字号仍是外观设置里的字号。

没拖动过时，对照卡贴在左右空档较大的一侧，宽度缩到那条空档里。左右都窄、上下还有空档时，对照卡贴到上下的空档里。段落框占满画面时，对照卡不盖在字上。拖对照卡右下角可以改大小，拖出的宽度会保留。画面变窄时对照卡只临时缩小。拖动过位置后，对照卡不再跟着框换边。

一次只画当前这一条，其他条不画。状态是「漏字」或「多字」时，两列上方标出少了或多了哪几个字。前后文在稿里出现两次时，不推测缺口位置。

右列只在对上确认单的恰好一行、而且这一行有字时，标题写「Excel标准」。片段、空行、多行和旧单都不把右列写成整句标准。整句里对得上的不同字符会标出来。没有段落范围时，错点框就是当前框，点它和点编号的效果一样。

浏览器宽度小于 720px 时，即使这台浏览器存的是开，也不显示对照卡。手机上本来不能逐条下结论。

## 取舍

- 对照卡显示时，画面只给对照卡留出空间，不再同时扣掉右栏的 320px。如果先减掉右栏宽度再适配页图，页图比例会算错。
- 其他条不画淡框。一次只看当前段落和当前错点。
- 没有坐标的条目不画框，留在右栏。如果画一个假的位置，审稿员会以为机器知道这条在哪里。
- 签字门槛不变。这个模式只改变「在哪里看」和「在哪里给这一条下结论」。签字规则见 [审稿合同](contracts/review.md#就地对照)。
- 平移和缩放时，对照卡的位置不触发核对页重新渲染。拖动后的位置不存进这台浏览器。

## 没采用的做法

- 用浮窗代替右栏。清单、待确认条数、签字和退回会失去固定位置。
- 让对照卡跟稿件一起放大。稿件放大后，对照卡上的字也会变大，超出卡片，没法读。
- 点一条仍只平移、不调整缩放。稿件很宽时，这一条会留在画面外，对照卡贴不到它旁边。
- 手机也显示对照卡。手机不能逐条下结论，对照卡只会挡住稿件。
