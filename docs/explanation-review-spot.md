# 为什么对照贴在框旁边

审核人要同时看见稿上的字和确认单上对得上的字。右栏清单还要留着，用来看整单还剩几条、以及签字和退回。就地对照把「这一条」从右栏里拿出来，贴到当前框旁边，清单不动。

数字、键名和函数见 [审稿合同](contracts/review.md#就地对照)。操作步骤见 [怎么使用就地对照](howto-review-spot.md)。

## 问题

0.31.1.16 之后，点一条问题不会自动放大。只有画面已经大于 1 倍，才会平移让框居中。详情在右侧 320px 清单里。宽稿上，眼睛要在墨迹和清单之间来回跳。

若把每条的全部分框都画出来，一条长句会碎成很多小框，不知道这一条的边界在哪。若拿掉右栏、改成满屏浮窗，整单进度和签字就没有固定位置。

## 做法

```
清单（右栏 320px，一直在）
稿件
  只画当前条：透明段落框 + 淡底错点框
  编号钉在错点外角
  对照卡在缩放层外面。未拖动时贴在框旁，拖开后留在放下处
        ┌──────── 当前段落 ────────┐  ┌─ 对照卡 440px ─┐
        │  稿上的这一段              │  │ 读到 / 标准或片段 │
        └──────────────────────────┘  └─────────────────┘
```

段落框宽和高同时超过页的 90% 才不画，然后退回错点框。不按页面积 30% 丢掉段落框。对照卡用屏幕坐标，不放进 `transform`。放大稿件时，框跟着走，字号仍是外观设置里的字号。

未拖动时，靠右缘放不下就改贴左边。框已经顶到上缘时，先放到框下面，避免卡被画布上沿裁掉。拖过之后不再跟着框换边。一次只打开当前这一条，其他条不画。

右列只在恰好一行、而且这一行有字时题「Excel标准」。片段、空行、多行和旧单都不把读到的几个字说成整句标准。

手机宽度小于 720px 时忽略这个开关，即使本机存的是开。手机本来就不能逐条下结论。

## 取舍

- 卡可见时取景只给对照卡留空，不再同时扣 320px 右栏。视口宽度不能先减掉右栏再拿去适配页图，否则页图比例会错。
- 其他条不画淡框。一次只看当前段落和当前错点。
- 没有坐标的条目不编造框，留在右栏。编一个顶排钉会让人以为机器知道位置。
- 签字门槛不改。逐字核对的「待人工确认」仍然不挡签字。这个模式只改「看」和「下这一条结论」的位置。
- 对照卡的 `left` / `top` 不走 React 状态。平移和缩放每帧都在动，若每次 `setState`，核对页会跟着重渲染。拖开后的位置也不写入本机。

## 没采用的做法

- 用浮窗换掉右栏。清单、待确认计数、签字和退回会失去固定位置。
- 把对照窗放进缩放层，让它跟稿件一起放大。要点文字会变得不可读。
- 点一条仍只平移、不取景。宽稿上范围会留在画面外，窗贴不到旁边。
- 手机也开。手机没有逐条结论，硬开窗只会挡住稿。
