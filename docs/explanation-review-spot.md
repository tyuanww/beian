# 为什么对照贴在框旁边

审核人要同时看见稿上的字和确认单应印的字。右栏清单还要留着，用来看整单还剩几条、以及签字和退回。就地对照把「这一条」从右栏里拿出来，贴到范围框旁边，清单不动。

数字、键名和函数见 [审稿合同](contracts/review.md#就地对照)。操作步骤见 [怎么使用就地对照](howto-review-spot.md)。

## 问题

0.31.1.16 之后，点一条问题不会自动放大。只有画面已经大于 1 倍，才会平移让框居中。详情在右侧 320px 清单里。宽稿上，眼睛要在墨迹和清单之间来回跳。

若把每条的全部分框都画出来，一条长句会碎成很多小框，不知道这一条的边界在哪。若拿掉右栏、改成满屏浮窗，整单进度和签字就没有固定位置。

## 做法

```
清单（右栏 320px，一直在）
稿件
  范围框 = 这一条可用分框的并集
  编号钉在范围外角
  对照窗在缩放层外面，贴范围右侧
        ┌──────── 范围 ────────┐  ┌─ 对照窗 300px ─┐
        │  稿上的这一段         │  │ 要点 / 应印 / 读到 │
        └──────────────────────┘  └────────────────┘
```

范围太大（并集达到页面积 30%）就退回原来的主框，避免一块几乎整页的框把别的字盖住。对照窗用屏幕坐标，不放进 `transform`。放大稿件时，框跟着走，字号仍是外观设置里的字号。

靠右缘放不下就改贴左边。框已经顶到上缘时，先放到框下面，避免窗被画布上沿裁掉。一次只打开当前这一条。

手机宽度小于 720px 时忽略这个开关，即使本机存的是开。手机本来就不能逐条下结论。

## 取舍

- 右栏还在，所以窄屏浮层打开时，取景要同时给对照窗和 320px 右栏留空。视口宽度不能先减掉右栏再拿去适配页图，否则页图比例会错。
- 一致项不全部画框。点到某一条一致时，只加画那一条。否则一页绿框会盖住真正要看的问题。
- 没有坐标的条目不编造框，留在右栏。编一个顶排钉会让人以为机器知道位置。
- 签字门槛不改。逐字核对的「待人工确认」仍然不挡签字。这个模式只改「看」和「下这一条结论」的位置。
- 对照窗的 `left` / `top` 不走 React 状态。平移和缩放每帧都在动，若每次 `setState`，核对页会跟着重渲染。

## 没采用的做法

- 用浮窗换掉右栏。清单、待确认计数、签字和退回会失去固定位置。
- 把对照窗放进缩放层，让它跟稿件一起放大。要点文字会变得不可读。
- 点一条仍只平移、不取景。宽稿上范围会留在画面外，窗贴不到旁边。
- 手机也开。手机没有逐条结论，硬开窗只会挡住稿。
