# 界面实现约束

本文件保存原 AGENTS 的对应工程合同，仅在涉及本主题时读取。产品行为不构成执行作业、发送消息或操作生产的授权。日期与验收状态是记录时快照，当前结论须绑定本次证据。路径除链接外均相对仓库根。

修改用户可见的布局、样式、文案或交互前先读 `DESIGN.md`；同轮已读且未变化可复用，不要求无关后端/文档任务读取。字体、色、间距、侧栏、核对页都以那份为准。锁定稿是 Figma Web 页，不是飞书顶栏。

- Figma：https://www.figma.com/design/BL3PGUjLGLPb9iUZMzRhD6 （`Web · 锁定稿`。侧栏材质对照：`Web · 侧栏材质对照`。iPad 页是探索，不是实现依据。）
- Ant Design 6 只当零件箱。`colorPrimary` = `#805898`，不要默认蓝，不要旧主色 `#722ED1`。
- 左侧玻璃侧栏切「审稿台 / 3D 打样 / 文件压缩 / 历史记录 / 设置」，「设置」只对管理员显示（`sideNavFor`）。展开 280px，折叠 76px。不要飞书顶栏。页底淡紫雾；侧栏与主区连成一块 28px 圆角工作场。≤1024 默认折叠，跨断点自动折叠，回桌面恢复原偏好；窄屏手动开合不覆盖桌面偏好。≤720 展开为遮罩抽屉。
- 侧栏顶用 `apps/web/ui/public/brand/logo-mark.png`。折叠时悬停变成展开按钮（同一 44pt）。完整 `shine-mage.png` 只放拒绝页。
- 左下角飞书头像 36px + `花名（真名）` 15px，例如 `天元（魏炜）`；服务端版本用弱化文字紧跟在姓名下面。
- 空审核单不画三栏。「外观」：主题、13–28px 字号（可手写）、侧栏材质（实心 / 毛玻璃 / 液态玻璃）、侧栏雾面对比度滑条、差异标记。只写 `localStorage`。所有人从左下头像菜单「外观」弹窗打开、即改即生效；管理员设置页里的「外观」分组照旧。深色走品牌紫雾，不是灰黑中台。
- 审稿：专属核对页，画布占右栏之外的剩余宽度。核对面优先 SVG，失败自动退高清 PNG；初始 1× 不施加恒等 transform，`will-change` 仅在平移时临时启用。钉和框分开关。关掉「对照」时只画当前字段；开着时只画当前这一条的段落框和错点框，细则见[审稿合同](review.md#就地对照)。「隐藏钉」只藏当前编号圆圈，永不恢复全页散钉。左图 CSS transform 缩放（1–6×），拖动走 rAF，禁止原生图片拖拽，不上 OpenSeadragon。核对页是 A 通铺三栏（0.31.1.16，`ReviewWorkspace` + `reviewFlat.ts` 的 `flatLayout`）：页面缩略图条 52px｜稿件｜右栏固定 320px，不能拖动调宽。视口 ≥1440 三栏常驻；720–1439 右栏默认收起，展开为 320px 浮层盖在稿件右侧；<720 只看稿和签字/退回，不显示缩略图条和右栏。右栏独立滚动，1440 常驻和浮层都能收起。全屏栏仍在核对页内，弹层跟随全屏根节点。右栏顶部是「待确认 N｜有错 N｜全部 N」标签和「收起」，上一条/下一条在页头位置「3/9」两侧的「‹ ›」；长字段与状态分行，窄栏证据纵排。当前字段及未保存备注按用户/任务/稿件版本隔离恢复；存储不可用时保留内存交互。当前字段先用跟随外观字号的正文写「核对要点」，再两列 Excel 应印与稿上读到，结论用「一致 1｜有错 2｜忽略 3」按钮；页头没有结论输入框，签字/退回都走确认框。禁止「AI 已过审」。
- 历史记录是侧栏 tab，不是第三张台。进行中的审稿/打样/压缩以及当前上传也列在里面，点进去看进度。
- 3D 打样在 2026-08-31 阶段不对业务开放；后续开放须有明确决定，不能按日期自动解禁。3D 打样和打样单主区白底深字（不是紫雾台，深色主题也是）；有地面图的新单走 grounded 成片（台面 `rgb(228,228,232)`），布局仍是一屏三列，grounded 框 5:6，不要上 1 下 2；第一屏 1440 核对卡后原位换成 full，点原图开灯箱看 full，预览和下载同一合成器，页头藏「下载 PPT」，灯光收到页头「调灯」后面；成片可切白底/银底/白桌白墙，当场合成不重打。没有地面图的旧单仍是上面三图看形、浅底+内描边、页头「下载 PPT」。缺印刷面时事故条在三图之上，可补则「补印刷面」。下面印刷面读字；每张图右上角下载，成片不提供 PDF 下载入口；独立净版展开 PDF 采用原尺寸下载；截图时下载钮藏起来。GLB 贴图为 WebP 且本机解码不了时按 `DESIGN.md`「3D 贴图不支持」降级：不挂模型，只显示已有静帧 poster（没有则浅灰骨架）和框底一句说明，不转圈、不给重试、复位禁用，下载仍是原始 GLB；缺字段或 PNG 照常加载。界面 QA 时标出本次检查范围内与 `DESIGN.md` 不符的实现；范围外发现单列建议，不自动扩展修复。

## 文件压缩与历史检索

路由 `/compress` 新建、`/compress/:id` 详情。沿现有上传会话恢复；受理后由服务端继续处理，页面轮询详情。PDF 单文件目标严格小于 10,000,000 字节，图片不套用该阈值。展示真实逐项状态/大小/节省比例、预览、下载、允许的失败重试；整批 ZIP 只包含可用结果。未知结果大小显示未生成或待完成，不能伪作零。

历史只调用 `/api/history` 做权限范围内检索与每页十条分页；组合关键词、类型、状态、创建人、日期和时区。按登录身份恢复查询、页码和滚动位置，改筛选回第一页，跨页选择不意外清除其他页；进行中不能批删。索引重建/失败要保留上次成功数据并提示，不能降级为浏览器全量旧列表。

七标签及净版按钮、物理尺寸、不可用/关稿未确认行为按 DESIGN 和[资产合同](packaging-presentation.md#净版展开与六面下载)执行；权限仍由后端判定，UI 不据六面或 GLB 假造净版。

## 设置仅管理员（前端，0.31.1.14）

- 前端唯一的管理员判断是 `apps/web/ui/src/authRole.ts` 的 `isAdmin()`：`/api/auth/me` 返回的 `role === "admin"`。后端角色与接口裁剪口径见[身份与设置合同](identity-settings.md)。
- 上传上限只在 `apps/web/ui/src/uploadLimit.ts` 的 `uploadLimitBytes(me)` 算（0.31.1.17）：取 `/api/auth/me` 可选字段 `upload_limit_bytes`（只认有限正数）和 99,000,000 字节（公网 100MB，十进制，留 1MB 给 multipart）中较小的值；没登录、换账号或 `/api/auth/me` 失败时用 99,000,000 字节。新建任务、文件压缩和核对页「上传新稿」都先按它预检，超了就不发请求，提示统一写「文件太大，请压到 NMB 以内再传（多份合计）」，N 按 1e6 向下取整、最少 1。服务端目前还不返回 `upload_limit_bytes`，所以线上一律按 99,000,000 字节。
- 非管理员侧栏不出「设置」；直接打开 `/settings` 只显示「这里只有管理员能看」和「回审稿台」按钮。`SettingsPage` 是懒加载且只在管理员分支渲染，所以非管理员不加载设置页代码，也不请求任何 `/api/settings*`。
- 设置页内会被后端 403 的动作按 `settingsActions(canAdmin)` 收起：「检查全部 / 检查连接」、「费用账单」分组与刷新、飞书「发送测试」，非管理员不显示也不发请求。
- `apps/web/ui/src/pages/settingsView.ts` 兼容后端省略字段：`value` / `last4` 缺失时表单初值为空、密钥占位只写「已填，留空不改」不露尾号；保存时被省略 `value` 的非密钥字段未改动就不提交，不把真值写成空；没有字段的分组不进菜单，所选分组被裁掉时回到「外观」。
