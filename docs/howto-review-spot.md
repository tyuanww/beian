# 怎么使用就地对照

在电脑上打开一份已经生成核对面的审稿，点一条问题，范围框进画面，对照贴在框旁边。右栏仍是整单清单。

合同数字和开关见 [审稿合同](contracts/review.md#就地对照)。为什么不把窗放进缩放层，见 [为什么对照贴在框旁边](explanation-review-spot.md)。

## 开始之前

- 用飞书登录后的审稿台，地址是 `/review/:id`。
- 浏览器宽度至少 720px。再窄是手机版，工具栏没有「就地对照」，也不能逐条下结论。
- 这一页已经有核对图。没图时没有框，也没有对照窗。

## 步骤

1. 打开核对页。工具栏「就地对照」默认是按下的（`aria-pressed=true`）。本机若曾经关掉，键 `wb_review_spot` 的值是 `off`。

2. 在右栏点一条问题，或点稿上的编号，或点当前框。没有段落范围时，错点框自己就是当前框，也可以点。三个入口是同一个动作：当前框进视口，旁边出现对照卡。同一页其他条不画。大框标出这一段，错点是框外的细下划线。卡默认约 440px，贴在大框左右空档较大的一侧，不压住大框；左右都窄就贴到上下的缝里。右下角可以拖动改大小，拖出的宽度会留下。左列在新逐字核对上题「稿上读到」；旧单没有整段时题「稿上片段」，并写「不是整段」。右列只有恰好对上确认单的一行、而且这一行有字时，才题「Excel标准」。对上多行、这一行是空的、或只是差异片段时，题「差异片段」或直接说明原因，并写「不是整句标准」。整句里对得上的不同字符标出。「漏字」或「多字」在两列上面标出少了或多了哪几个字。底下是「上一项」「下一项」，以及「一致」「有错」「忽略」。

3. 「上一项」「下一项」只在当前右栏标签里走，到头就停，不绕回。抬头可以拖。拖开之后换下一条，卡留在放下的位置；点「回到框旁」才贴回当前框。抬头移动不满 4px 仍算点击。

4. 要回到旧的右栏详情：再点一次「就地对照」。开关变成未按下，画面回到整页，详情回到右栏，段落框也不再画。这个选择写在这台浏览器里，下次还在。

## 怎么确认生效

- 按下时，对照窗的 `data-testid` 是 `review-spot`，`aria-label` 是「对照贴在这条旁边」。
- 关掉后再点一条：还没放大的整页不会自动放大，详情在右栏。
- 开发机可跑 `apps/web/ui` 里 `review-workspace.spec.ts` 的「就地对照」。那条测试自己把开关打开。其他核对页测试在启动前把 `wb_review_spot` 写成 `off`，所以它们仍在测旧路径。

## 对不上时看这里

- 工具栏没有「就地对照」：宽度不到 720px。拉宽窗口，或换电脑。
- 右栏仍展开着这一条，稿上没有范围：这条没有可用框。窗上或栏里会写「没找到位置，请看整页」。漏字框铺得太大时写「没框住这一行」。
- 点了范围却没有窗：工具栏「隐藏框」是关的。先点「显示框」。
- 对照字被稿件放大撑得很大：不应出现。窗不在 `.canvas-zoom` 里面。若字跟着稿件变大，就是回归。
- 已签字的单仍画当前这一条，但「一致 / 有错 / 忽略」按原规则点不了。
- 这个开关不改变签字和退回。逐字核对里的「待人工确认」仍然不挡签字。
